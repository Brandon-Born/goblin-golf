# Characters

The first proof of concept includes three selectable goblins. These are starting concepts and can be renamed or redesigned once the game's tone sharpens.

## Character Stat Scale

Use a 1 to 5 scale for prototype readability.

| Stat | Meaning |
| --- | --- |
| Power | Maximum throw distance |
| Accuracy | Aim consistency and control forgiveness |
| Spin | Ability to shape curves and recover flight |
| Wind Read | Resistance to wind penalties |
| Putting | Control during the putting mini game |

## Grib Ninesnatch

Play style: Balanced beginner

Personality: Confident, theatrical, and convinced every shot was intentional.

| Stat | Value |
| --- | --- |
| Power | 3 |
| Accuracy | 3 |
| Spin | 3 |
| Wind Read | 3 |
| Putting | 3 |

Design notes:

- Best default character for the first playable build.
- Should make the core controls feel fair.
- Useful baseline for tuning other goblins.

## Morga Mosswhack

Play style: Control specialist

Personality: Patient, superstitious, and always listening to what the grass says.

| Stat | Value |
| --- | --- |
| Power | 2 |
| Accuracy | 5 |
| Spin | 3 |
| Wind Read | 4 |
| Putting | 4 |

Design notes:

- Lower distance but easier fairway placement.
- Good for demonstrating accuracy and wind-read advantages.
- Strong candidate for new players who prefer consistency.

## Skrak Boomarm

Play style: Power thrower

Personality: Loud, reckless, and delighted by any throw that scares the gallery.

| Stat | Value |
| --- | --- |
| Power | 5 |
| Accuracy | 2 |
| Spin | 4 |
| Wind Read | 2 |
| Putting | 2 |

Design notes:

- Longest throws with the most risk.
- Good for showing dramatic hooks, skips, and risky flight paths.
- Should be fun without becoming the obvious best choice.

## Character Selection Requirements

The character select screen should show:

- Character name
- Character art
- Play style label
- One-line personality quote
- Stat bars
- Confirm/select action

The selected goblin should affect gameplay in the first playable prototype, even if the effects are simple multipliers.

Do not add active special abilities in the first prototype. Character differences should come from stat-based modifiers only.
